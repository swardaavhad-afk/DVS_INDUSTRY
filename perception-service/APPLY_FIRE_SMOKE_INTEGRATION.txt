FIRE/SMOKE LIVE INTEGRATION

This package extends the existing perception service. It does not include the trained model.
Required local checkpoint:
  models/fire_smoke_yolov8n_v1.pt

Apply
1. Back up the current source/config files listed below.
2. Extract this ZIP into the perception-service project root.
3. Replace files when prompted.
4. Run the py_compile command from the accompanying chat instructions.

Behavior
- Dedicated YOLO fire/smoke model; ByteTrack is not used for deformable fire/smoke regions.
- Main pipeline runs at 10 FPS and evaluates fire/smoke every 2 cycles (~5 FPS).
- Fire threshold 0.50; smoke threshold 0.50.
- Persistence: 3 positive evaluations among the latest 5.
- One persistent class => PROBABLE fire_smoke event requiring human verification.
- Persistent fire + smoke => CONFIRMED possible-fire signal, severity CRITICAL.
- A PROBABLE -> CONFIRMED escalation updates the existing incident instead of creating a duplicate.
- Tier downgrades are suppressed during the same active episode.
- Evidence extraction and JSONL reporting use the existing pipeline.
