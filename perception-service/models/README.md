# Model checkpoints

`fight_lstm_demo.pt` is synthetic and must not be used for real CCTV.

The real training command writes `fight_lstm.pt` here. Large checkpoints are intentionally excluded from the source ZIP.

## Runtime checkpoints

The following checkpoints are referenced by `config/thresholds.yaml` but are
not included in this repository:

- `fight_lstm.pt` — generated by the real fight LSTM training command.
  `fight_lstm_demo.pt` is synthetic and must not be used for real CCTV.
- `fight_r3d18_v1.pt` — RGB fight-classification checkpoint.
- `fire_smoke_yolov8n_v1.pt` — fire/smoke detection checkpoint.

Provide the required checkpoint files in the `models/` directory before
running the corresponding detection modules. The training or acquisition
procedure for each checkpoint must be documented separately. Do not treat
the demo checkpoint as a substitute for a trained model.
